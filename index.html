How it works

1 · The data

Year-end closing values of the S&P 500 index (Yahoo Finance, ^GSPC) from 1929 to 2023, the same data request as Mini Project 2. Each year's return is the change from one year-end close to the next, which gives 94 annual returns from 1930 to 2023.

2 · One simulated future

Each year until retirement, the simulator draws a return and updates the balance:

end of year: B = B × (1 + r) + C
start of year: B = (B + C) × (1 + r)

With the normal model, r is drawn from a normal distribution with the historical mean and standard deviation (a return can't fall below −100%). With the historical model, r is one of the 94 real years, picked at random with replacement.

3 · Thousands of futures

Repeating this 10,000 times (or the number you choose) gives a spread of final balances. The chance of reaching the goal is the share of simulations that end at or above it. Percentiles use linear interpolation, the same method as NumPy.

The random numbers are seeded, so anyone can reproduce a result exactly. The website engine is checked against an independent Python version on every update.

What it leaves out

  • Dividends: the index is price only, so returns are understated by roughly 2 to 4 points a year over long periods.
  • Inflation and taxes: all amounts are in today's nominal dollars, before tax.
  • Diversification: the whole balance is in the S&P 500, with no bonds or cash.
  • The past is not a forecast: future returns may differ from 1930–2023.
